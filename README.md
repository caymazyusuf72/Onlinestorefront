# Modern E-Ticaret Sitesi

Bu proje, Next.js, TypeScript ve Tailwind CSS kullanılarak oluşturulmuş modern ve zengin özelliklere sahip bir e-ticaret sitesi altyapısıdır. Çevrimiçi bir mağaza kurmak için sağlam bir başlangıç noktası sunar.

## Özellikler

- **Ürün Kataloğu:** Detaylı açıklamalar, resimler ve incelemelerle ürünlere göz atın.
- **Gelişmiş Sıralama ve Filtreleme:** Ürünleri kategoriye, markaya göre kolayca filtreleyin veya fiyata ve popülerliğe göre sıralayın.
- **Alışveriş Sepeti:** Ürün eklemek, çıkarmak ve adet güncellemek için tam fonksiyonel bir sepet.
- **Kullanıcı Profilleri:** Kullanıcıların oturum açması, profil bilgilerini görmesi ve site temasını kişiselleştirmesi için sistem.
- **Dinamik Tema:** Kullanıcıların seçebileceği dört mevsim (İlkbahar, Yaz, Sonbahar, Kış) teması.
- **Satın Alma Akışı:** Müşterilerin siparişlerini tamamlaması için bir ödeme sayfası ve sipariş onay ekranı.
- **Statik Sayfalar:** Hakkımızda, Blog, Kariyer, SSS ve daha fazlası için hazır sayfalar.
- **Duyarlı Tasarım:** Mobil cihazlar ve masaüstü bilgisayarlarda sorunsuz bir deneyim.

## Kullanılan Teknolojiler

- **Framework:** Next.js (App Router)
- **Dil:** TypeScript
- **Stil:** Tailwind CSS
- **UI Bileşenleri:** Shadcn/ui
- **Form Yönetimi:** React Hook Form & Zod
- **Durum Yönetimi:** React Context

## Kurulum ve Başlatma

Projeyi yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:

1.  **Bağımlılıkları Yükleyin:**
    ```bash
    npm install
    ```

2.  **Geliştirme Sunucusunu Başlatın:**
    ```bash
    npm run dev
    ```

3.  **Tarayıcıda Açın:**
    Uygulamayı görüntülemek için tarayıcınızda `http://localhost:9002` adresini ziyaret edin.
